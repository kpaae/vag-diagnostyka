Jak uruchomić z prawdziwym adapterem
  1. Aplikacja to jeden plik HTML. Umieść go pod adresem HTTPS, np. GitHub Pages, Netlify Drop albo Cloudflare Pages. Bluetooth ze strony działa tylko przez HTTPS.
  2. iPhone: zainstaluj przeglądarkę Bluefy z App Store, otwórz w niej adres aplikacji, włącz zapłon i naciśnij Bluetooth. iPhone łączy się tylko z adapterami BLE (Bluetooth 4.0+).
  3. Windows: otwórz aplikację w Chrome lub Edge. Adapter BLE: przycisk Bluetooth. Klasyczny adapter Bluetooth najpierw sparuj w ustawieniach Windows (PIN zwykle 1234 lub 0000), potem naciśnij Port COM i wybierz port „Standard Serial over Bluetooth”.
  4. Po połączeniu aplikacja sama skanuje moduły i zbiera błędy. Kasowanie błędów zawsze wymaga potwierdzenia.
  5. Kolory progów są orientacyjne. Nie zastępują danych serwisowych konkretnego silnika.
